# Megjegyzések Claude-nak

## Hol keresd, amit nem találsz
- Minden átkerült a **Mac Studio**-ra, de az **eredeti fájlok valószínűleg a „nyers videók” meghajtón** vannak.
- Ha valamit nem találsz (pl. a meglévő edzés-app vagy a kaja-app forrását), **nézd meg a „nyers videók” meghajtón a Claude Code mappát**.
- Ehhez a felhasználó gépe kell (Remote Control). A felhőből csak akkor érhető el, ha a mappa a Claude asztali appban
  (Settings → Claude Code → Remote Control) meg van osztva, és nem rejtett mappában van.

- `apu-torna/` – tornáztató app Apunak (tablet, Tailscale-en futó mini szerver). Lásd `apu-torna/README.md`.
